# LiveTransX 🎙️  →  🌐

**完全离线的实时语音翻译**

LiveTransX 在你的设备本地完成全部语音转写与翻译，无需联网，不上传音频，对话隐私 100% 保留在你手中。

---

## ✨ 功能介绍

### 免费功能
- 🎤 **麦克风实时翻译** — 边说边显示双语字幕
- 🧠 **Apple Speech Analyzer** — 基于 iOS 26 的本地语音识别引擎
- 🌍 **Apple Translation** — 覆盖 35+ 语言，自动检测源语言
- 📱 **iPhone & iPad** — 双平台原生支持

### Pro 订阅功能
- 🪟 **悬浮翻译窗口** — 画中画浮窗，与其他 App 同时使用
- 📺 **屏幕共享翻译** — 翻译视频通话、会议、视频中的音频
- 📁 **音频文件翻译** — 上传 mp3/wav 文件进行批量转写翻译
- 📝 **SRT 字幕导出** — 导出双语、原文或译文字幕文件

### 支持的语言
中文（简体 & 繁体）、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、意大利语、阿拉伯语、泰语、越南语、印尼语、马来语、印地语、土耳其语、荷兰语、波兰语、瑞典语、丹麦语、芬兰语、捷克语、希腊语、匈牙利语、罗马尼亚语、波斯语、菲律宾语等 35+ 种语言。

## 🔒 隐私至上

- ✅ **完全本地处理** — 音频绝不离开你的设备
- ✅ **无需注册账号** — 打开即用，无需登录
- ✅ **无追踪** — 零分析 SDK，零广告
